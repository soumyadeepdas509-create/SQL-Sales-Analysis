# SQL Sales Analysis

## Project Overview

This project is a simple SQL-based sales analysis project created to practice and demonstrate important SQL skills used in data analysis.

The project analyzes sales data to understand revenue performance across different regions, products, categories, and months.

## Tools Used

- MySQL
- SQL
- GitHub

## Dataset

The sales table contains the following information:

- Order ID
- Order Date
- Customer Name
- Product
- Category
- Region
- Quantity
- Price

## Analysis Performed

The project includes 10 SQL queries:

1. View all sales
2. Filter sales from the East region
3. Sort products by price
4. Calculate revenue for each order
5. Generate an overall sales summary
6. Calculate revenue by region
7. Find products with revenue above 10,000
8. Classify orders based on revenue
9. Calculate monthly revenue
10. Calculate revenue by category
