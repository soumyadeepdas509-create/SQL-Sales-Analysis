# SQL Sales Analysis Project

A beginner-friendly SQL project focused on analyzing sales data using MySQL. This project demonstrates essential SQL operations commonly used in data analysis, including filtering, sorting, calculations, aggregation, grouping, and conditional logic.

## Project Overview

This project uses a small sales dataset containing information about orders, customers, products, categories, regions, quantities, and prices.

The main objective is to use SQL queries to analyze sales performance and answer basic business questions related to revenue, products, regions, categories, and monthly sales.

## Dataset

The `sales` table contains the following columns:

| Column | Description |
|---|---|
| `order_id` | Unique ID of each order |
| `order_date` | Date when the order was placed |
| `customer_name` | Name of the customer |
| `product` | Product purchased |
| `category` | Product category |
| `region` | Sales region |
| `quantity` | Number of units sold |
| `price` | Price per unit |

The dataset contains 12 sales orders covering the first three months of 2026.

## SQL Operations Covered

The project contains 10 SQL analysis operations:

1. View all sales
2. Filter sales by region
3. Sort products by price
4. Calculate revenue for each order
5. Generate an overall sales summary
6. Analyze revenue by region
7. Find products with revenue above 10,000
8. Classify orders based on revenue
9. Analyze monthly revenue
10. Analyze revenue by category

## How to Run

1. Install MySQL or use a MySQL-compatible environment.
2. Open the `sales_analysis.sql` file.
3. Run the complete SQL script.
4. The `sales_analysis` database and `sales` table will be created automatically.
5. Run the analysis queries to view the results.
